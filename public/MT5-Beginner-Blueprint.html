Set stake (lots)

  1. F9 → Volume 0.01
  2. SL below entry (long) / above (short)
  3. TP at next level — ≥ 2× SL distance
  4. Risk ≤ 1% of balance

Use Tools tab R:R calculator before Send.

Best pair & times

  • EUR/USD — start here
  • USD/JPY — after 1 month demo
  • 8 AM – 12 PM ET — best window (overlap)
  • Avoid Saturday / early Sunday

Screenshot (Analyze tab)

  • Last 20–40 candles on the RIGHT
  • Clear wicks + bodies, 4H or Daily
older candles │ RECENT ← app reads here

When to END trades

  • TP hit → done
  • SL hit → accept, no revenge
  • Invalidation beyond wick → exit
  • 2 losses/day → stop

4-week path

  • W1: Demo + F9 + 0.01 lots
  • W2: 4H + Analyze before every trade
  • W3: Daily top-down + Tools check
  • W4: 20+ journaled trades; no live yet
